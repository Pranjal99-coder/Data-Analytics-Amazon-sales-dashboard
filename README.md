# Data-Analytics-Amazon-sales-dashboard
An interactive Power BI dashboard designed to analyze Amazon sales performance, revenue, orders, profit, returns, and product/category performance over time. The dashboard helps businesses identify top-performing products, understand sales trends, and monitor profitability and customer returns.

Short Description / Purpose
The Amazon Sales Analytics Dashboard is an interactive business intelligence solution that provides a consolidated view of e-commerce performance.

It enables users to track key metrics such as Total Revenue, Total Orders, Total Profit, and Return Rate, while also analyzing monthly trends, product categories, top products, and returned products.

The dashboard can support sales strategy, product management, inventory planning, profitability analysis, and e-commerce decision-making.

Tech Stack

The dashboard was developed using the following technologies:

Power BI Desktop – Main data visualization and dashboard development platform.
Power Query – Used for data cleaning, transformation, and preparation.
DAX (Data Analysis Expressions) – Used to create calculated measures and KPIs such as revenue, orders, profit, return rate, and month-over-month comparisons.
Data Modeling – Used to establish relationships between sales, product, category, and returns data.
Power BI Visualizations – Used for KPI cards, line charts, bar charts, tables, and comparative performance visuals.
File Format – .pbix for Power BI development and .png for dashboard preview.



The dashboard uses an e-commerce sales dataset containing information related to orders, products, categories, revenue, profit, and returns.

Date → Order → Product → Category → Sales/Revenue → Profit → Return

Features / Highlights
• Business Problem

E-commerce businesses generate large volumes of transactional data, making it difficult to quickly understand which products and categories are driving revenue and profitability.

Without an interactive analytics solution, businesses may struggle to answer questions such as:

How much revenue and profit are we generating?
How many orders are being placed?
Which product categories generate the most orders?
Which products generate the highest revenue and profit?
Are sales increasing or declining over time?
How many products are being returned?
Which product types are most frequently ordered or returned?
How is the current month's performance compared with the previous month?
6. Goal of the Dashboard

The primary goal is to transform raw e-commerce transaction data into an interactive sales intelligence dashboard.

The dashboard enables decision-makers to:

Monitor overall sales performance.
Track revenue, orders, profit, and return rate.
Analyze monthly sales trends.
Identify high-performing product categories.
Identify top products by revenue, orders, and profit.
Monitor customer return behavior.
Compare current-month performance with the previous month.
Identify products that may require inventory, pricing, or quality attention.
